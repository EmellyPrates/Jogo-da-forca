# Dados

Esta pasta guarda arquivos de persistencia simples em texto.

## Arquivos

- `palavras.txt`: palavras do jogo, uma por linha, no formato `PALAVRA;dica` (sem acentos na palavra).
- `recorde.txt`: melhor pontuacao registrada.
- `ranking.txt`: base para ranking de jogadores (melhoria futura).

## Observacao

Evite versionar dados pessoais reais dos jogadores.
